# Pick Our Sunday

A one-page date picker: picnic & board games, or paint & sip with a shared playlist. Answers are sent to Formspree, so anyone can fill it out without an account.

- Live at: https://torresig77-png.github.io/date-invite/sunday/
- Answers go to: https://formspree.io/f/xkjobwje (set in `config.js`)
